## 🛠️ Fix
- **After updating, the launcher didn't open for several minutes** (it only showed in Task Manager): it installed the mods that came with the update before showing its window, and replacing each older bundled mod took about 30 seconds. The launcher now opens straight away and installs them in the background ("Installing the update's mods... (n of N)" - Play waits until it's done), and replacing them takes about a second.

If you're stuck on 2.1.4's invisible launcher: leave it running for a few minutes - it opens by itself when it's done.
